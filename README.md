# 📚 Biblioteca Municipal

## Descrição

O projeto **Biblioteca Municipal** é uma aplicação desenvolvida em Java para gestão básica de uma biblioteca. O sistema permite o registo, consulta e pesquisa de livros, bem como o controlo de empréstimos e devoluções.

## Funcionalidades

* Registar novos livros
* Consultar catálogo completo
* Pesquisar livros por título
* Pesquisar livros por autor
* Efetuar empréstimos
* Efetuar devoluções
* Visualizar estatísticas

## Requisitos

* Java JDK 8 ou superior
* NetBeans, Eclipse ou IntelliJ IDEA

## Como Executar

bash
javac Biblioteca\_Municipal.java
java Biblioteca\_Municipal
